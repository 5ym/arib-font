# BIZ UDゴシックの字の部品を組んで作る字 (tools/src/parts.rs が読み、格子の上で組んでからほかの字と同じく丸める)。
# 座標は em 1024 (BIZ UDゴシックの em 2048 を半分にしたもの)。字形の中心は (512, 389)。
#
#   U+XXXX 字 [送り幅] = 部品 ; 部品 ; …     送り幅は無ければ 1024
#   U+XXXX 字 -> U+YYYY                      同じ字形を使う
#   @名前 = 部品 ; …                         型。部品の代わりに @名前 と書く
#
# 部品:  [-]元 [{輪郭の番号,…}] [[切り抜き]] [置き方] [w太さ]
#   -        抜く (重ねたものから白く抜く)
#   元       BIZ UDゴシックの字 1 つ (U+XXXX でも)。または図形:
#            ring(cx,cy,r,w) 輪 / disc(cx,cy,r) 丸 / frame(x0,y0,x1,y1,w) 四角の枠 / rect(x0,y0,x1,y1) 四角
#   {…}      元の字の輪郭のうち使うもの (番号は元のフォントの並び。build/ の部品の見本で確かめる)
#   [x0,y0,x1,y1] か [x,y x,y x,y …]  元の字の座標で切り抜く矩形か多角形
#   置き方   > x0,y0,x1,y1  切り抜き (無ければ使う輪郭の墨の枠) を、この枠いっぱいに伸ばす
#            ~ x0,y0,x1,y1  縦横同じ比でこの枠に収め、真ん中に置く
#            +dx,dy         大きさはそのまま動かす
#            cxX            大きさはそのまま、墨の横の真ん中を X に置く
#   w太さ    縮めて細った (伸ばして太った) 線を戻す太さ。既定は漢字の線の太さ 84、w0 で戻さない。
#            横に縮めたら横にだけ、縦に縮めたら縦にだけ膨らませる (図形には効かない)
#
# 元のフォントにある字でもここに書けばこちらが勝つ (半角と全角の幅を v2.x にそろえる字)。
